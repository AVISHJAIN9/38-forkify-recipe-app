# Frequently Asked Questions: Forkify Modern Recipe Search Planner

### 1. What is Forkify Modern Recipe Search Planner?
Modern recipe search, meal serving size recalculation, and bookmarking web application.

### 2. What technology stack does it use?
Built with Vanilla JavaScript (MVC Architecture), External Recipe API, SASS.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/38-forkify-recipe-app/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
